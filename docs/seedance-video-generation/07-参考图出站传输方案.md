# 参考图出站传输方案

## 背景

当前 Volcengine Ark 图片和视频策略会把 `imageUrls`、`firstFrameImageUrl`、`lastFrameImageUrl`、`referenceImageUrls` 原样写入模型请求。该做法要求这些值必须是模型厂商可直接访问的公网 URL。

实际部署中，业务侧图片经常是以下形式：

- `/media/...` 本地静态资源路径；
- `/art-styles/...` 或 `/api/art-styles/...` 预设画风资源；
- 应用、对象存储或内网服务可访问，但模型云端不可访问的 HTTP URL；
- 已经上传或前端传入的 `data:image/...;base64,...`。

因此，“应用能读取图片”和“模型厂商能通过 URL 下载图片”必须拆开处理。

## 目标

- Ark 出站请求不再强依赖参考图 URL 公网可访问。
- 不改变数据库和接口字段语义，业务字段仍保存轻量媒体引用。
- Data URL 只存在于模型请求的内存对象中，不落库、不返回给前端。
- 先覆盖图片类输入：图片生成参考图、视频首帧、视频尾帧、视频参考图。

## 非目标

- 本期不把视频、音频参考媒体转为 base64；`referenceVideoUrls`、`referenceAudioUrls` 继续按 URL 传输。
- 本期不新增数据库字段、不新增上传接口、不改变项目/资产的 base64 入库限制。
- 本期不自动修复首尾帧与参考媒体混用问题；该问题继续由既有“首尾帧优先 + 两阶段流程”处理。

## 方案

新增统一的出站媒体解析组件：

```text
业务媒体引用
  ├─ data:image/...;base64,...
  ├─ /media/...
  ├─ /art-styles/... 或 /api/art-styles/...
  └─ http(s) URL
        │
        ▼
GenerationMediaInputResolver
        │
        ▼
data:<mime>;base64,<payload>
        │
        ▼
Volcengine Ark image / image_url.url
```

### 输入解析规则

| 输入类型 | 处理方式 |
| --- | --- |
| `data:image/...;base64,...` | 校验格式和 base64 后直接复用 |
| `/media/...` | 从默认存储路径或 `./data/media` 安全读取本地文件 |
| `/art-styles/...`、`/api/art-styles/...` | 复用 `PresetArtStyleResourceResolver` 从 classpath 读取 |
| `http://`、`https://` | 服务端下载图片后转为 Data URL，下载过程复用当前模型的代理配置 |
| 其他值 | 返回明确业务错误，不再原样透传给 Ark |

### Provider 接入规则

| Provider / 场景 | 出站格式 |
| --- | --- |
| Volcengine Ark 图片生成 `image` | Data URL 列表 |
| Volcengine Ark 视频首帧/尾帧 `image_url.url` | Data URL |
| Volcengine Ark 视频 `reference_image` | Data URL |
| Volcengine Ark 视频 `reference_video/reference_audio` | 保持 URL |
| OpenAI 图片编辑 | 继续 multipart，不在本期重构 |
| DashScope / GoogleFlow | 已有策略内转换能力，本期不强行迁移 |

## 与两阶段流程的关系

Data URL 只解决“模型拿不到图片内容”的传输问题，不改变 Ark 的 content 互斥规则。

如果同时需要“参考图一致性”和“首尾帧控制”，仍然走：

```text
参考图/角色图/风格图
        │
        ▼
生成首帧/尾帧关键图
        │
        ▼
只携带 firstFrameImageUrl / lastFrameImageUrl 生成视频
```

不能在同一个视频请求中同时提交 `first_frame/last_frame` 和 `reference_image/reference_video/reference_audio`。

## 风险控制

- 限制单张图片最大读取大小，避免 base64 请求体过大。
- 下载远程图片时校验响应 MIME，非图片响应直接拒绝。
- 日志不打印完整 Data URL。
- `/media/...` 读取时校验路径不能逃逸存储根目录。
- 真实 Ark 视频接口对 Data URL 的支持仍需后续联调验证；当前参考工程 `waoowaoo` 已采用该模式。

## 本期代码边界

- 新增 `GenerationMediaInputResolver`，集中处理图片 Data URL 转换。
- `VolcengineImageStrategy` 在提交 `image` 前调用该组件。
- `VolcengineVideoStrategy` 在构造图片类 `content` 前调用该组件。
- 增加单元测试覆盖 Data URL、HTTP 下载、`/media` 本地读取和 Volcengine content 转换。
