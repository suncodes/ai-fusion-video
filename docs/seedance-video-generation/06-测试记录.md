## 测试矩阵

| 场景 | 预期结果 |
| --- | --- |
| 首帧 + 尾帧 | 发送 `first_frame + last_frame`，不发送任何参考媒体 |
| 首帧 + 参考图 | 进入首帧模式，参考图被裁剪并记录 warning |
| 首尾帧 + 参考视频/音频 | 进入首尾帧模式，参考媒体被裁剪并记录 warning |
| 只有尾帧 | 本地返回 `VIDEO_LAST_FRAME_REQUIRES_FIRST_FRAME` |
| 无帧 + 参考图/视频/音频 | 进入多模态参考模式 |
| `/media/...` 参考图 | 服务端读取本地媒体并转为 `data:image/...;base64,...` |
| HTTP 参考图 | 服务端下载图片并转为 `data:image/...;base64,...` |
| 非图片 HTTP 响应 | 本地拒绝，不提交 Ark |
| duration=3 | 本地拒绝，不调用 Ark |
| duration=4 或 15 | 允许提交 |
| duration=16 | 本地拒绝，不调用 Ark |
| 参考图生成首尾帧成功 | 保存帧后只提交一次视频请求 |
| 参考图生成关键帧失败 | 不提交视频，返回关键帧阶段错误 |
